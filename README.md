# Clearly Pinterest Content Planner & Analytics Tracker — live demo

Try-before-you-buy demo of the Clearly Pinterest planner: plan pins on a visual
content calendar, score every pin against a plain-language SEO checklist, and
import Pinterest's own CSV exports for board and audience analytics.

This is the **locked demo build** — pre-filled with sample data, edits last until
refresh, saving and backup are disabled. The full product is a single offline
HTML file sold on Etsy; it saves everything automatically and never needs an
account, a login, or a subscription.
